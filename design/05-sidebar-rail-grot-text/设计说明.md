# 方案 05 · sidebar-rail / grot-text

五个候选里留下的那一个：极窄竖轨放模块切换，主区像一张摊开的书页，详情从底部升起来，可以用手拖走。交互按 Apple 的物理方式写。

## 种子怎么变成这套样子

| 维度 | 取值 |
| --- | --- |
| 底色 | 石板日 `#dde2e6`，表面 `#eef1f4` |
| 强调色 | `hsl(176 59% 25%)` 深青 |
| 版式 | 图标轨 + 内容台 |
| 字体 | 中性 grotesque（界面）+ 书籍衬线 Charter（正文），标题 Didot |
| 形状 | 圆角 11px，行距 1.7，行宽 72ch，均衡，实线描边 |
| 动效 | 短促线性，但详情面板单独用弹簧 |

## 版式

- 左侧 68px 竖轨只放四枚图标（阅读、词库、练习、英语基础），图标是内联 SVG，统一 1.6px 线宽。竖轨顶端是品牌方块，中间是模块，底部是工具。
- 竖轨右边还有一条 232px 的栏目栏，放书卷、章号、筛选条件。它在竖轨之后、主区之前，宽度固定。
- 主区占满剩下的宽度，像一页摊开的书。英文正文用 Charter，界面用 Helvetica Neue，标题用 Didot。
- 详情不是右侧抽屉，而是底部升起的面板，顶部一条拖动把手。

## 交互：这一套的重点

面板升起和落下的手感按 Apple 的物理方式写：

- 弹性用阻尼 1.0 的弹簧，response 0.3 秒左右，不会来回晃。
- 甩动收尾用动量投影：按每帧 0.998 的衰减算落点，`current + (v/1000)·d/(1-d)`，所以轻轻一甩和快速一甩停在不同位置。
- 拖动是 1:1 跟手的，指针事件用 `setPointerCapture` 抓住，不会在指针滑出把手时断掉。
- 越界有橡皮筋：越拖越沉，位移按 `overshoot·dim·0.55/(dim+0.55·|overshoot|)` 收敛，永远拉不到头。
- 松手时如果投影落点超过面板高度的 28%，或者甩速超过 700，就收走；否则弹回原位。
- 中途可以打断：从当前呈现值起跳，把松手的速度带进新的弹簧，不是从 0 重来。
- 系统开了"减弱动态效果"就直接到位，不做动画。
- 面板材质是半透明层加背景模糊，并提供"降低透明度"时的纯色回退。

其余交互：点词查词、划词查词、阶段三态、练习逐字符反馈、按 Tab 偷看。

## 借了哪些做法

- 竖轨 + 标签的做法来自 Apple 平台应用的侧边栏：图标轨收模块，文字栏收上下文。
- 底部面板的拖动把手与松手判定参考 iOS 的 sheet 交互。
- 查词浮层的内容顺序沿用 LinguaCafe。

## 书页对开

竖轨把左边压到 68px，内容台宽 1060px，对开各 516px，版心 372px。资料面板在这一套是底部浮层，对开时它仍然从底部升起，遮住的只是下半屏，不影响读经文。

页高 693px，是竖轨与栏目的横向占用没吃掉多少垂直空间的结果，创世记一章摊 5 个对开。页高足，中文那页的行与行之间就留得住气，不显挤。

英文那页用书籍衬线（Charter），中文那页用宋体，一页一种字面，合起来才像一页真的对开书而不是两段文字。纸是米白里压 5.5% 深青，摊在石板日的桌面上；这一套底色偏冷，纸偏暖，冷暖之间那点差就是"这是一张纸"的全部说服力。

翻页除了底部的「前一页 / 后一页」，还接了键盘 ← →，和底部面板的拖拽一样按苹果那套手势习惯来：对开翻页是内容位移，不做淡入淡出。

段落切分沿用和合本的十节段落：节号以大号数字挂在文字栏左边；英文页每节另起一行小标题（"Adam and Eve" 一类），中文页不印——英中两边各按自己的规矩来。

## 已知取舍

- 竖轨 68px + 栏目栏 232px 固定占掉 300px，1440px 宽下正文仍有约 1100px，但更窄的窗口会明显拥挤。
- 面板遮住底部内容是这个方案的代价：正文长了要往上滚，才能看到被压住的那几行。
- 模糊材质在低端机器上开销不小，所以加了纯色回退，但没有做性能自动降级。
- 对开本的翻页是整页替换，没有翻页动画——真书有，这里没有，因为这一套的动效预算留给底部面板了。
