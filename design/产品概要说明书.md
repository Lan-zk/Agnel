# 圣经英语学习工具箱 · 产品概要说明书

**版本：** V0.1（产品概念版）
**产品性质：** 免费、开源、非商业、无 AI、离线优先
**产品定位：** 以英文《圣经》为特色阅读材料，结合通用英语知识和多样化学习工具的个人英语学习应用。

## 一、产品背景与目标

### 1.1 产品背景

传统英语学习应用通常将单词、语法、阅读和练习划分为独立模块，或要求用户遵循预先制定的课程。

本产品采用不同的思路：以真实英文阅读为主要入口，让用户在阅读过程中自然使用查词、翻译、词汇积累和练习工具。

《圣经》作为产品的特色阅读材料，具有完整的篇章结构、丰富的词汇、可对照的中英文译本，以及适合持续阅读的内容体系。

但产品不局限于圣经英语，还应支持现代通用英语的基础知识学习，为阅读英文书籍、文章和技术文档提供帮助。

### 1.2 产品目标

- 提供完整、舒适的中英圣经阅读体验。
- 帮助英语初学者认识单词、理解短语和英文句子。
- 提供词汇记忆、打字、默写等多样化练习。
- 支持音标、语法、词根及词族等基础英语知识学习。
- 让阅读材料、词汇知识和学习练习自然关联。
- 保持工具的独立性，让用户自主选择学习内容和方式。

**核心理念：以阅读为中心，以工具辅助学习，不以课程约束用户。**

## 二、目标用户

主要面向希望借助英文《圣经》学习英语的中文使用者，特别是英语基础较弱、希望提高英文阅读能力的成人学习者。

产品同时适合：

- 希望通过中英对照阅读英文圣经的基督徒。
- 喜欢通过真实文章而非单纯教材学习英语的用户。
- 希望积累基础词汇、学习语法与发音的自学者。
- 需要简单、离线、无账号依赖的个人学习工具的用户。

不以考试培训、英语等级认证或学校课程教学为主要定位。

## 三、整体产品形态

### 3.1 阅读器优先

产品采用 **Reader-first（阅读器优先）** 的设计。

用户打开应用后直接进入阅读器，并恢复上次的阅读内容及位置。

不设置强制学习计划或课程仪表盘。

应用整体由四个主要部分组成：

| 产品模块 | 定位                 | 主要内容                           |
| -------- | -------------------- | ---------------------------------- |
| 阅读     | 默认入口、核心场景   | 中英圣经、普通英文文章、查词、翻译 |
| 词库     | 个人语言知识管理     | 单词本、词典、短语、词形和词族     |
| 练习     | 独立的语言训练空间   | 打字、拼写、默写、填空、句子练习   |
| 英语基础 | 独立的知识学习工具箱 | 音标、基础词汇、语法、词根与派生   |

### 3.2 两类学习内容

**圣经英语**

以英文圣经为主要素材，提供中英对照、阅读查词、经文词汇积累、经文跟打和填空练习。

**通用英语**

提供独立于圣经的基础英语内容，包括常见词汇、日常短语、音标、语法、句法、词根，以及普通英文文章和技术英语示例。

两类内容共用同一套词典、单词本和练习工具，不建立相互隔离的学习系统。

## 四、核心功能概要

### 4.1 阅读中心

产品最主要的使用场景。

**圣经阅读**

- 支持完整的英文与中文圣经。
- 按书卷、章节和经节组织内容。
- 支持逐节中英对照与英文优先两种阅读布局。
- 中文译文可按需显示或隐藏。
- 支持阅读进度保存。
- 阅读过程中可以查询、收藏单词和短语。
- 支持从经文进入相关学习和练习工具。

**普通英语阅读**

- 提供普通英语文章的阅读能力。
- 复用圣经阅读器中的查词、收藏和学习功能。
- 不将学习内容局限于圣经经文。

阅读功能的设计方向是简洁、舒适、低干扰，兼顾正常阅读与语言学习。

### 4.2 单词与词库

以统一的个人词库管理学习过程中积累的单词。

主要能力包括：

- 英汉词典查询。
- 单词音标、词性、释义和发音。
- 收藏单词与短语。
- 手动添加单词。
- 保存单词出现的原始语境。
- 展示词形变化、相关词和常见搭配。
- 查看个人收藏、已练习词汇与错误记录。

单词不仅有独立的词典含义，也保留它在圣经或其他文章中的实际用法。

### 4.3 英语练习

参考打字学习类开源项目，以主动输入和回忆为核心。

**单词练习**

- 跟打：看着英文单词输入。
- 默写：根据释义回忆英文拼写。
- 听写：根据读音输入英文单词。
- 自测：隐藏部分提示，检查记忆结果。

**句子与经文练习**

- 英文句子跟打。
- 逐句默写。
- 经文或文章填空。
- 使用收藏的单词和短语进行练习。

**练习辅助**

- 即时拼写反馈。
- 错词收集与重复练习。
- 简单的练习记录。
- 可选的间隔复习。

练习强调语言知识的掌握，不以打字速度或游戏成绩作为英语水平的唯一评价指标。

### 4.4 基础英语知识

基础英语是独立的学习模块，不要求必须通过圣经阅读才能使用。

**音标与发音**

提供英语音素、国际音标、元音与辅音、音节、重音、发音示例及基础练习。

**语法与句法**

提供词性、句子成分、基本句型、时态、短语结构、从句等常见知识的解释和例句。

**词根与派生**

提供常见前后缀、词根、词形变化及词族关系，并通过可视化关系图辅助理解。

关系图需要明确区分词形变化、派生关系与真实词源关系，避免将词义相近或拼写相似的单词错误归为同源词。

**基础词汇与短语**

提供现代英语常用词、固定搭配和实际例句，不局限于圣经词汇。

以上内容均可独立查询、阅读和练习，暂不要求形成固定课程。

## 五、核心学习体验

产品应支持一条自然的学习路径：

**阅读材料 → 发现不理解的内容 → 查询与学习 → 收藏积累 → 选择练习 → 返回阅读。**

例如，用户阅读创世记 1:1 时遇到 `created`：

1. 查看单词含义、音标和发音。
2. 了解它与基本词形 `create` 的关系。
3. 查看相关词族，例如 `creation`、`creator`。
4. 收藏到个人单词本，并保留来源经文。
5. 选择拼写、默写或经文填空练习。
6. 在未来阅读其他文章时继续认识和使用这个词。

这个流程只是产品支持的能力，用户不必按照固定顺序执行。

所有工具均应能够独立使用，也能够在需要时互相连接。

## 六、视觉与交互设计方向

### 6.1 整体风格

产品风格应当简洁、克制、安静，优先保证阅读舒适度和学习效率。

避免过度游戏化、复杂的统计界面、密集的信息卡片以及不必要的装饰。

圣经特色主要通过阅读内容、书卷结构、经文编号和整体排版体现，不依赖大量直观宗教图案。

### 6.2 不同场景的设计特点

| 场景     | 设计方向                               |
| -------- | -------------------------------------- |
| 阅读     | 电子书式排版、舒适留白、低干扰         |
| 查词     | 快速获取信息，尽量不打断阅读           |
| 词库     | 结构清晰、方便检索、突出关联知识       |
| 练习     | 沉浸式、专注当前任务、反馈清晰         |
| 英语基础 | 参考工具书与知识卡片，注重理解和可视化 |

### 6.3 关键交互原则

- 进入应用即进入阅读。
- 两种中英阅读布局由用户自主切换。
- 阅读时尽量不跳转到其他页面。
- 学习工具可以独立打开。
- 从工具返回时保留原来的阅读位置和状态。
- 用户可以自由学习，不强制每日任务、课程进度或连续打卡。

## 七、参考开源项目与借鉴方向

本产品不是上述开源项目的复刻，而是选择其成熟的产品思想、交互方式和部分可复用能力，结合圣经阅读场景形成自己的产品特色。

| 项目                                                         | 主要特点                                             | 本产品借鉴方向                                   |
| ------------------------------------------------------------ | ---------------------------------------------------- | ------------------------------------------------ |
| [Qwerty Learner](https://github.com/RealKai42/qwerty-learner) | 键盘输入结合词汇记忆，提供音标、发音、默写与输入反馈 | 沉浸式单词打字、即时纠错、专注型练习界面         |
| [TypeWords](https://github.com/zyronon/TypeWords)            | 多种背词模式、文章跟打、词汇信息、错词管理           | 多模式单词练习、句子与经文跟打、填空、错词练习   |
| [Read Frog](https://github.com/mengxi-ream/read-frog)        | 双语阅读、选词翻译、阅读中积累词汇及复习             | 中英阅读布局、即时查词、词汇收藏、阅读与学习结合 |
| [Lute v3](https://github.com/LuteOrg/lute-v3)                | 通过真实文本学习语言，建立词汇与阅读上下文的关联     | 阅读内查词、词形关联、词汇熟悉程度、语境记录     |
| [LinguaCafe](https://github.com/simjanos-dev/LinguaCafe)     | 自托管语言阅读器，集成词典、词库和复习               | 阅读器与词库联动、词汇管理、阅读后复习           |
| [Anki](https://github.com/ankitects/anki) / [FSRS](https://github.com/open-spaced-repetition/awesome-fsrs) | 记忆卡片及间隔复习机制                               | 可选的长期记忆与复习调度                         |

**借鉴重点：**

- Qwerty Learner：练习的专注性。
- TypeWords：练习形式的丰富性。
- Read Frog：阅读和查词的流畅性。
- Lute：通过真实内容积累词汇。
- LinguaCafe：阅读、词库、复习之间的关联。
- Anki / FSRS：长期记忆管理。

代码复用与产品借鉴应分开考虑。Qwerty Learner、TypeWords、Read Frog、LinguaCafe 采用 GPL 系列许可证，Lute 使用 MIT 许可证。实际复制代码时需要逐项遵守许可证，并单独核查词典、音频、教材等数据的授权。

## 八、内容资源方向

**圣经资源**

- 英文：Berean Standard Bible（BSB）。
- 中文：简体中文和合本。
- 采用合法可分发的本地经文数据。
- 保留未来支持其他译本的可能性。

**语言学习资源**

- ECDICT：候选英汉词典数据。
- CMU Pronouncing Dictionary：候选英语发音词典。
- Open English WordNet：候选词汇语义关系资源。
- 英语基础知识内容参考权威词典、语法书及语言教学资料。

外部数据需要核验准确性与分发许可证。特别是词典来源、语音资源和词源信息，不应仅因为某个 GitHub 仓库开源就认为其中所有内容都可自由使用。

## 九、产品边界与长期方向

### 当前产品不追求的内容

- 完整的 A1–C2 课程体系。
- AI 教师、AI 翻译或自动生成的语法解释。
- 复杂的个性化学习模型。
- 强制学习计划与每日任务。
- 社交、排行榜、竞技和游戏化奖励。
- 神学注释、原文释经或讲道资料管理。
- 多用户运营及商业化系统。

### 未来可以探索的方向

在独立学习工具成熟后，可以进一步探索：

- 不同英语水平的学习内容组织。
- 更丰富的阅读材料和分级阅读。
- 学习记录及长期词汇复习。
- 通用英语知识与圣经语境的交叉索引。
- 可选择的学习路径与课程体系。

这些属于潜在的发展方向，不作为当前产品设计的前提。

## 十、产品总结

本产品的核心形态是：

**以圣经阅读器为入口，以通用英语知识为基础，以词汇积累和多样化练习为核心能力的离线英语学习工具箱。**

它具有三个主要特点：

**第一，内容特色明确。** 以中英圣经对照作为主要阅读场景，同时允许学习普通英文文章和现代英语知识。

**第二，学习工具相互关联。** 从阅读中发现的单词、短语和句子，可以自然进入词库、词根知识和练习工具。

**第三，保持用户自主性。** 不依赖完整课程，不强制规定学习节奏。用户可以自由阅读、查询、记忆和练习。

产品不追求一次性构建一个完整的英语教学平台，而是提供一组结构统一、可长期使用、能够自然扩展的语言学习工具。

**最终目标：让用户通过持续阅读和实际练习，逐步从认识零散英文单词，发展到能够独立理解英文句子、文章与书籍。**
